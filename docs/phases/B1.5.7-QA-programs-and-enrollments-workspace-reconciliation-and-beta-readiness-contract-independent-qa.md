## 5. Explanation of the `??` Git Status Marker

In `git status --porcelain=v1`, the prefix `??` is Git’s standard marker for an **untracked** path: a file that exists in the working tree but is not yet in the index or HEAD commit. It does **not** mean modified, deleted, conflicted, or ignored. The B1.5.7 contract was therefore present only as a new untracked documentation artifact from the prior reconciliation phase.
