## 6. Security closure

| Control | Evidence |
| --- | --- |
| Organization scoping | Reads filter `organization_id`; adapters pass membership-resolved org id to RPC |
| Membership resolution | `resolveOrganizationContext`; fail-closed on missing/auth |
| Owner/admin/staff/viewer | Permission helpers + RPC role matrix; viewer mutations denied early |
| Viewer archived exclusion | Default list excludes archived; detail unavailable for non-owner/admin |
| Staff no archive / evaluate | Local gate + DB RPC roles |
| Suspended / no membership / unknown role | Org resolver + empty permissions |
| Second tenant / missing item | Uniform `ATTENTION_ITEM_UNAVAILABLE` |
| RPC-only writes | Adapters call `.rpc` only; `attentionAdaptersAllowDirectTableWrites() === false` |
| No service role | Authenticated client paths only |
| Audit DB-authoritative | Events created inside B1.7.3 RPCs; app does not insert events |
| Immutable events | B1.7.3 UPDATE trigger + privilege deny (unchanged) |
| Fail-closed enums/errors | Mappers + normalize rules for B1.7.3 raise messages |
| Protected path | Middleware uses `isProtectedApplicationPath` including Attention |
| Open-redirect prevention | Existing safe-return rejects external/protocol-relative/encoded bypasses |
| Hidden navigation | `ATTENTION_NAV_VISIBLE = false`; AppShell renders no Attention link |
