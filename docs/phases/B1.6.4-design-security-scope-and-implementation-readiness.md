### 3.2 What “deferral” means in this phase

In ZyntixAI repository language for B1.6.4, **deferral** means:

> The **product decision** during B1.5 that Progress was not yet shipped, expressed as **placeholder copy** on Enrollment/Program detail (and related PE surfaces) stating that Progress tracking is deferred to a later phase.

**B1.6.4 remediates that stale presentation** now that Progress list/detail/mutations exist (B1.6.2–B1.6.3), and adds **contextual Progress entry points** from PE detail.

## 4. User problem, result, and primary journey

### 4.1 User problem

Authorized members opening Enrollment or Program detail still read that Progress is deferred to a later phase, even though `/progress` (including record/void/correct for eligible roles) is live. Contextual navigation from PE → Progress is missing.

### 4.2 User result (testable)

From Enrollment or Program detail, a member can:

1. Read accurate Progress guidance (no stale “later phase” claim for shipped Progress);
2. Open Progress filtered to that Enrollment or Program when permitted;
3. From Enrollment detail (eligible roles + eligible enrollment status), open Record Progress with `enrollmentId` prefilled via existing `/progress/new?enrollmentId=…`.

Viewer remains read-only for mutations (no Record CTA).

### 4.3 Primary journey

```text
Enrollment or Program detail
→ Progress section (accurate copy)
→ View progress (filtered list) and/or Record progress (enrollment-prefilled, role-gated)
→ Existing Progress workspace (B1.6.2–B1.6.3)
→ no new Progress RPC; no PE lifecycle mutation
```

### 4.4 Current vs desired behavior

| Surface | Current | Desired (B1.6.4) |
| --- | --- | --- |
| Enrollment detail | Copy: “Progress tracking within this enrollment is deferred to a later phase.” | Accurate Progress section + links/CTAs |
| Program detail | Copy: “… Progress tracking remains deferred to a later phase.” | Accurate Progress guidance + link to Progress filtered by `programId`; keep Enrollment links |
| Programs list empty | “Enrollment and progress tools follow in later phases.” | Truthful copy (Enrollment + Progress already exist) |
| Progress create | Supports `?enrollmentId=` already | Wired from Enrollment detail CTA |
| Progress list | Supports `enrollmentId` / `programId` filters already | Linked from PE detail |
| PE status/archive/edit | Working | **Unchanged** |
