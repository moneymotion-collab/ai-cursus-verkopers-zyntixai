## 6. List-Workspace Findings

- Org scope: `resolveProgramPageOrganization` then overwrite `urlState.org` with membership-derived `organizationId`; list queries use that ID (browser `org` is selection hint only).
- Search trimmed/capped; status and delivery allowlisted; invalid values warn and reset.
- Archived filter gated by `canViewArchivedProgramFilter` (owner/admin); staff/viewer requests cleared.
- Sort allowlist (`name|updated_at|status|created_at`); direction allowlist; pageSize capped at 100.
- Empty vs no-results distinct; create CTA role-aware; detail links present.
- No foreign-tenant enumeration path found in list loader.

---

## 7. Create-Flow Findings

- Fields: name, deliveryMode (default `self_paced`), description only — no org/role/status/`expected_end_date` inputs.
- Page loader returns `action_unavailable` for staff/viewer.
- Action resolves membership via `resolveOrganizationContext`; mutation checks `canCreateProgram`; RPC `create_program`.
- Pending ref blocks double submit; errors mapped without raw DB exposure.
- Success navigates to Program detail via typed `programId`.

## 8. Detail-Workflow Findings

- History empty / error / ready / hidden states supported.
