## 7. Completion Contract

Required: display name, organization name, business type, primary audience, primary offering, primary goal. Team size optional.

```text
Complete iff organizations.onboarding_completed_at IS NOT NULL
```

- First complete sets timestamp to transaction `now()`
- Repeated complete preserves original timestamp
- DB CHECK requires enums + non-empty name when timestamp set
- Profile display name enforced in RPC (cannot be expressed on org CHECK alone)

---

## 8. Partial-Save Contract

Mode `draft` on `apply_organization_onboarding`:

- Only provided fields overwrite (null args leave existing values)
- `p_clear_team_size_band` clears optional team size
- Does not set completion
- Owner-authorized; organization must match active owner membership
- Zod draft schema validates provided enums/lengths before RPC

## 9. Authorization and Tenant Isolation

| Case | Behavior |
| --- | --- |
| Unauthenticated | `not_authenticated` |
| No membership | `membership_required` |
| Non-owner (e.g. admin) | `owner_required` (TS + RPC) |
| Arbitrary foreign org id | `organization_not_found` / RPC owner check |
| Multiple memberships without org id | `organization_ambiguous` |
| Cross-tenant write | Denied (membership + owner role) |

RLS on `organizations` remains enabled; normal use does **not** require service role.

## 13. Concurrency and Retry Behavior

- Per-organization advisory transaction lock in RPC
- Completion timestamp write-once
- Draft/complete retries safe (idempotent complete)
- Concurrent completes serialize on lock; first timestamp wins
