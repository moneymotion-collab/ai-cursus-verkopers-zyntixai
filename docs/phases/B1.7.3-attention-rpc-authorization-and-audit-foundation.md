## 7. Public RPC surface and roles

| RPC | Roles |
| --- | --- |
| `create_manual_attention_item` | owner/admin/staff |
| `record_attention_signal` | owner/admin/staff |
| `acknowledge_attention_item` | owner/admin/staff |
| `assign_attention_item` | owner/admin/staff |
| `update_attention_severity` | owner/admin/staff |
| `resolve_attention_item` | owner/admin/staff |
| `dismiss_attention_item` | owner/admin/staff |
| `archive_attention_item` | owner/admin |
| `evaluate_attention_rules` | owner/admin |

Expire is **private** (`private.expire_attention_item`), invoked only from evaluate. No restore RPC.

Fail-closed messages: `not authenticated`, `insufficient role`, `attention item not found`, `enrollment not found`.

---

## 8. Audit model

`attention_item_events` records `created`, `status_changed`, `assigned`, `severity_changed`, `signal_recorded`, `archived`, `detection_updated` with optional before/after fields, reason, source (`manual`|`rule`|`system`), actor, payload.

---

## 9. RLS

- Mutations: no INSERT/UPDATE/DELETE grants or policies (RPC-only).  
- SELECT: owner/admin see archived; members see non-archived; Signals/Events join parent Item visibility.  
- Signal UPDATE remains trigger-blocked; app DELETE remains privilege-denied.

---

## 10. Rule evaluation (manual Owner/Admin only)

`evaluate_attention_rules` implements `enrollment_no_recent_progress` (14 UTC calendar days; eligible `active|paused` non-archived; progress `max(occurred_at)` non-voided else `enrollment.created_at`). Upserts non-terminal Item + appends Signal; expires non-terminal Items that are no longer stale. **No scheduler wiring.**
