## 5. Selected Query-Parameter Contract

| Surface | Parameters | Meaning |
| --- | --- | --- |
| `/enrollments` | `customerId`, `programId` (optional, UUID) | Server-side filters + context banner labels |
| `/enrollments/new` | `customerId`, `programId` (optional, UUID) | Prefill only when id is in eligible create options |
| All | `org` | Existing org selection — not granted by context params |

Invalid UUIDs → warning + omitted. Foreign/missing valid UUIDs on list → `context_unavailable` (no label leak). Context never grants role or organization authority.

## 6. Customer-Detail Integration

- **View enrollments** → `/enrollments?org=…&customerId=…`
- **New enrollment** only when `canShowCreateEnrollmentWorkflow(role)` and customer is non-archived with status `onboarding` or `active`
- Existing enrollment summary rows link to Enrollment detail when `detailHref` is present
- Customer mutation workflow links unchanged

---

## 7. Program-Detail Integration

- **View enrollments** → `/enrollments?org=…&programId=…`
- **New enrollment** only when create-capable role and program is non-archived with status exactly `active`
- Staff may receive View + New Enrollment; Program edit/lifecycle/archive/restore remain omitted for Staff/Viewer
- Open-enrollment count retained; no embedded Enrollment table

---

## 8. Enrollment-List Contextual Filtering

- URL parser populates `filters.customerId` / `filters.programId`
- Labels resolved via `resolveEnrollmentListContext` (org-scoped)
- Context banner with **Clear context** (removes only relationship params; resets `page` to 1)
- Filter form preserves context via hidden inputs
- Existing search/status/archived/sort/pagination retained

---

## 9. Relationship-Aware Empty States

| Situation | Behavior |
| --- | --- |
| Valid context, no other filters, empty | “No enrollments for this customer/program…” + optional Create CTA when role may create |
| Other filters active, empty | Existing “No enrollments match…” + clear filters |
| Context unavailable | Dedicated unavailable panel; no foreign labels |
| Global empty | Existing “No enrollments yet” |

Create form is not embedded in the list.

---

## 10. Enrollment-Create Preselection

- Loader parses context IDs; preselects only when present in eligible option lists
- Ineligible/foreign context → generic notice; no preselected label
- Both preselected → soft duplicate-open notice when an open enrollment exists; create action/RPC remain authoritative
- Users may still change selections; submitted IDs revalidated server-side

---

## 11. Contextual Return Navigation

- List ↔ detail ↔ create continue to use Enrollment list UrlState / `org` query preservation
- Auth `resolveSafeReturnPath` allowlist already covers Enrollment paths; tests added for contextual query strings
- No second redirect-security system

## 13. Enrollment-Detail Program Navigation

## 14. Role-Permission Matrix

| Contextual action | Owner | Admin | Staff | Viewer |
| --- | ---: | ---: | ---: | ---: |
| View Customer Enrollments | Allow | Allow | Allow | Allow |
| View Program Enrollments | Allow | Allow | Allow | Allow |
| New Enrollment from eligible Customer | Allow | Allow | Allow | Deny |
| New Enrollment from eligible Program | Allow | Allow | Allow | Deny |
| Use contextual create preselection | Allow | Allow | Allow | Deny (create page unavailable) |
| Open related Customer/Program from Enrollment | Per existing related-record visibility | | | |

Enforcement: presentation gating + create-page loader deny + create action/RPC + org-scoped queries. UI hiding alone is not relied upon.

---

## 15. Customer Eligibility Handling

`isCustomerEligibleForEnrollmentCreate`: not archived and status ∈ `{onboarding, active}`. Matches create-option filters; RPC remains authoritative.

---

## 16. Program Eligibility Handling

`isProgramEligibleForEnrollmentCreate`: not archived and status exactly `active`. Draft/paused/retired/archived Programs do not receive New Enrollment.

---

## 17. Duplicate-Open Protection

Unchanged unique open-enrollment rule. Soft notice on create when both contexts preselect an existing open pair. Create action/RPC still reject duplicates.

---

## 18. Tenant-Isolation Controls

- Organization from authenticated membership
- Context IDs resolved only with `organization_id` equality
- Foreign IDs → unavailable / no preselect / no label
- No service-role client
- Query params cannot set role
