## 2. Owner product decision (authoritative)

### Official direction

```text
B1.7 — Attention Foundation
```

### Why

Published ZyntixAI critical product sequence:

```text
Program → Enrollment → Progress → Attention → Next Best Action
```

B1.5 Programs/Enrollments and B1.6 Progress are production closed. Attention is the next necessary capability in this chain.

### Product goal

B1.7 designs (and later builds) the **generic foundation** so ZyntixAI can determine:

* which customer, participant, or enrollment record needs attention;
* why attention is needed;
* which signals provide evidence;
* how urgent the situation is;
* who is responsible;
* the current status of the attention item;
* when it was resolved, dismissed, or expired.

B1.7 does **not** build an autonomous recommendation engine.

### Foundation-first

```text
APPROVE ATTENTION FOUNDATION-FIRST
```

Attention currently lacks authoritative schema, domain model, types, RPC, RLS, lifecycle, status model, workspace, fixtures, and browser-QA contract. A full design/security/readiness phase is required **before** implementation. Direct implementation start is forbidden.

## 12. Security / threat baseline

Inherit B1.6: authentication ≠ authorization; active membership required; suspended ≠ active; Viewer read-only; foreign IDs safe deny; no client-trusted org IDs; server/RPC/RLS leading.

| Scenario | Risico | Preventie | Bewijs/test |
| --- | --- | --- | --- |
| Membership-loos | Unauthorized access | Active membership resolution | F1-A |
| Suspended | Status bypass | Active-only resolver | F1-B |
| Viewer mutation | Privilege escalation | Role enforcement | Viewer |
| Org A → Org B | Cross-tenant leak | RLS/RPC scoping | Tenant B fixtures |
| Foreign parent ID | Cross-org relation | Server validation | PK probes |
| Direct URL | UI bypass | Server authorization | Browser QA |
| Duplicate submit | Duplicate data | Idempotency / dedup | Repeated request |
| Archived / terminal object | Hidden mutation | Eligibility check | Fixtures (later) |
| Autonomous AI action | Unsafe automation | Out of B1.7 | Contract denylist |
