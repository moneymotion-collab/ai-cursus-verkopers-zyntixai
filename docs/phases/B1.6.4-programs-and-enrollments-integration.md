## 4. View / Record contracts

### View contracts

| Prop / link | Contract |
| --- | --- |
| `EnrollmentProgressLinks.viewProgressHref` | Always when PE detail loads; `buildProgressListHref({ organizationId, enrollmentId })` |
| `ProgramProgressLinks.viewProgressHref` | Always when Program detail loads; `buildProgressListHref({ organizationId, programId })` |
| Viewer | View link allowed (read-only Progress rules unchanged) |

### Record contract (Enrollment detail only)

| Gate | Rule |
| --- | --- |
| Helper | `canShowEnrollmentRecordProgressEntry({ role, enrollmentStatus, isArchived })` |
| Role | owner / admin / staff via `canShowRecordProgressWorkflow`; **viewer → no Record CTA** |
| Status | **active** or **paused** only; pending / completed / cancelled → no CTA |
| Archive | archived → no CTA |
| Href | `buildProgressCreateHref({ organizationId, enrollmentId })` → `/progress/new?...` |
| Program detail | **No** Record CTA |

UI visibility is hint-only; Progress server actions/RPC remain authoritative.

## 5. Query params

| Param | Use |
| --- | --- |
| `org` / `organizationId` | Tenant context on Progress list and create hrefs when selected org is known |
| `enrollmentId` | Filter Progress list from Enrollment detail; prefill create from Record CTA |
| `programId` | Filter Progress list from Program detail |

Routes used (existing — no new mutation routes):

| Route | Use |
| --- | --- |
| `/progress?enrollmentId=&org=` | View Progress for enrollment |
| `/progress?programId=&org=` | View Progress for program |
| `/progress/new?enrollmentId=&org=` | Record Progress prefilled |
