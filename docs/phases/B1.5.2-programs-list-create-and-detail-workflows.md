## 10–13. Search, Filter, Sort, Pagination

| Concern | Behavior |
| --- | --- |
| Search | Trimmed, max 200; `q` URL param |
| Status | Allowlisted `draft\|active\|paused\|retired`; invalid → warning + reset |
| Delivery | Allowlisted six modes; invalid → warning + reset |
| Archived | Owner/admin only; staff/viewer requests cleared with warning |
| Sort | `name\|updated_at\|status\|created_at`; default `updated_at` |
| Direction | `asc\|desc`; default `desc` |
| Pagination | Page ≥ 1; pageSize ≤ 100; filter submit resets page to 1 |
| URL | Shareable within org; malformed values do not crash |

Parsing lives in `program-list-search-params.ts` (no duplicated domain enums in route files).

| Item | Result |

| Route | `/programs/new` |
| Fields | name (required), deliveryMode (required, default `self_paced`), description (optional) |
