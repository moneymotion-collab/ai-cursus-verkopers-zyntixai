## 9. Edit Workflow Summary

Owner/Admin open `/programs/[programId]/edit`, update name/deliveryMode/description via `updateProgramAction` → `update_program` RPC. Archived programs cannot be edited. Staff/Viewer see permission denial without a mutation form.

---

## 10. Lifecycle Workflow Summary

Owner/Admin open `/programs/[programId]/status`, select a permitted transition and optional reason via `transitionProgramStatusAction` → `transition_program_status`. History rows appear on detail after success. Soft-archive is separate.

---

## 11. Archive Workflow Summary

Owner/Admin confirm archive via `archiveProgramAction` → `archive_program`. Cancel leaves state unchanged. Open enrollments block archive (UI warning + RPC). Archive does not change lifecycle status.

---

## 12. Restore Workflow Summary

Owner/Admin confirm restore via `restoreProgramAction` → `restore_program`. Clears `archived_at` only; does not alter lifecycle status.
