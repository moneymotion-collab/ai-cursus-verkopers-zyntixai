## 4. Founder-Led / Build-in-Public Boundary

### Allowed

- Documented planning progress and milestones
- Architecture and problem-framing (from Launch Scope)
- Lessons learned from building
- Honest readiness state ("in development", "not yet available")
- Spec-level workflow explanations with disclosure

### Prohibited

- Fake customers, testimonials, revenue, or usage stats
- Showing unimplemented features as live product
- Credentials, secrets, private customer data
- Beta-open or launch-ready claims without authorization
- Public pricing or paid CTAs

Do not create actual posts in this phase.

## 5. Funnel Architecture

```text
Awareness (problem: operational fragmentation)
  → Problem recognition (P1 themes)
  → Product understanding (O1–O10 intent)
  → Trust / proof planning (what evidence will exist)
  → Interest capture (follow / waitlist)     ← CURRENT MAX STAGE
  → Future: Beta eligibility (if authorized)
  → Future: Commercial consideration (if pricing + launch authorized)
```

**Buy now** is not a current funnel stage.
