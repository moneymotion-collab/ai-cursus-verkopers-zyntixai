## 4. Funnel Architecture (Planning)

Current CTA must stop before paid activation.

```text
Awareness
  → Problem recognition (P1)
  → Product understanding (O1–O10)
  → Trust / proof planning (what evidence will exist later)
  → Interest capture (waitlist / updates)
  → Future: Apply for beta (only if beta authorized)
  → Future: Paid consideration (only if pricing authorized + billing implemented)
```
